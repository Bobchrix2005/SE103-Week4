What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they are added to the main branch. Reviewers can examine the files, identify mistakes, and suggest improvements. Once the changes are approved, the pull request can be merged into main.

Why branches and pull requests are used together:
Branches allow developers to work on new features without directly changing the main branch. Pull requests provide a way to review and discuss those changes before merging them. Using both helps teams collaborate, find errors early, and maintain a more organized project.
