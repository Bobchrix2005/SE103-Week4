What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they are merged into the main branch. Reviewers can examine the changes, provide feedback, and approve the work before it becomes part of the main project.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately without directly modifying the main branch. Pull requests allow those changes to be reviewed and discussed before merging. Together, they support collaboration and help prevent mistakes from reaching the main project.
