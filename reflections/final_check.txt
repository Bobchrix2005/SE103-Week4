What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they become part of the main project. It gives reviewers an opportunity to examine the code, provide feedback, and suggest improvements before the changes are merged.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately without directly modifying the main project. Pull requests provide a way to review those changes before merging them into the main branch. Together, they make collaboration safer and more organized.
