Problem:
Search a list of names for one target name and report whether it was found.

Input:
- A list of names
- One target name

Output:
- "Found" or "Not found"
- An error if the list is empty

Pseudocode:
START
    INPUT names
    INPUT target

    IF names is empty THEN
        OUTPUT "Error: list is empty"
    ELSE
        SET found = FALSE

        FOR EACH name IN names
            IF name = target THEN
                SET found = TRUE
                BREAK
            END IF
        END FOR

        IF found = TRUE THEN
            OUTPUT "Found"
        ELSE
            OUTPUT "Not found"
        END IF
    END IF
END
